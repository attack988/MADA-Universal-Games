# MADA Universal Games

A bilingual Arabic/English Windows game launcher for Ubuntu.

## Features
- Arabic and English interface
- Right-to-left Arabic support
- Windows game library
- Wine-based game launching
- EXE, RAR, ZIP and 7Z import
- Per-game Wine prefixes
- Launch options and error logs
- Dark interface

## Installation

Requires Ubuntu and an internet connection for dependencies.

```bash
chmod +x install.sh
./install.sh
```

Launch MADA Universal Games from the application menu.

## العربية

مشغّل لألعاب Windows على Ubuntu باستخدام Wine،
يدعم العربية والإنجليزية وإدارة مكتبة الألعاب.

## Important

This repository contains the launcher source code only.
It does not include games or copyrighted game assets.

Wine compatibility varies by game.
